## 🚀 Live Demo & Deployment

### Quick Local Preview
Simply open `index.html` in any modern web browser, or run a local server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.

### GitHub Pages Deployment
1. Go to your repository on GitHub: `Settings` → `Pages`.
2. Under **Branch**, select `main` (or `master`) and folder `/ (root)`.
3. Click **Save**. Your portfolio will be live at:
   `https://chaithu44-tech.github.io/bhuvaneshwari-portfolio/`
